# Bibliography

This is the local citation source for the framework. Each row becomes one BibTeX
entry (via `generate_reference_index.py` / the LaTeX build). Citation auto-supplement
(`AUTO_CITE_WEB=false`, the default) will only ever pull keys from this table — nothing
is invented, and web-sourced entries must carry a verifiable URL before being added here.

Evidence grades: A (peer-reviewed) > B (arXiv/preprint) > C (tech report/system card) > D (blog/model card) > E (third-party/weak).
