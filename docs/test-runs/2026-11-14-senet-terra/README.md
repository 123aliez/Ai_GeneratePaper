## 实际发现与归因

本次未发现需要改变整体流水线架构的问题。篇幅属于内容与约束执行表现，引用和训练目标属于材料缺口，小节误判属于已有类型推断逻辑缺陷；仅凭这一轮结果不能归因于模型价格。

1. **篇幅明显偏短。** 配置为 12 页，生成大纲约 3825 词，最终程序统计正文约 1720 词、按 700 词/页估计约 2.5 页。相关工作只有三句话，约 60 个英文词；摘要按空白分词约 133 词，低于要求的 150–250 词。当前流程会提醒或保留待办，但不会因篇幅不足停止。材料仅有一张结果表、三份较简略文献笔记，也限制了可写内容。
2. **实验设置的小节类型误判。** `05-experimental-setup-experiments/brief.md` 明确声明 `type: experiments`，但小节 “Dataset and Evaluation Protocol” 被 `evaluation` 别名识别为 results，“Training and Model Comparison” 被 `model` 识别为 method。运行日志显示 `sections=1:results,2:method`，契约粗检因此按多类型跳过。最终正文仍覆盖了数据集、评测和训练设置，但契约实际应用范围不正确。本次未修改该路由逻辑，作为后续局部修复项记录。定位：`agents/chapter_type.py` 的 `normalize_type` 和 `resolve_run_route` 中的小节标题猜测。
3. **材料缺口保留在稿中。** 方法章含一处 `[DESIGN DETAIL NEEDED]`（训练目标未提供）；实验设置含两处 `[CITATION NEEDED]`（ImageNet 数据集、He 初始化的原始引用未入库）。中英文稿均保留这些标记。
4. **文献索引仍残留旧工具提示，已修复。** 上游索引和笔记视图原本要求模型调用 `read_reference` / `search_reference_text`，与本地无工具架构不符。已改为附入 `note:<key>` 和返回 `<lookup>`，提交 `8de0e33`；本次正文生成使用了修正后的索引。
5. **核验通过与内容完整有区别。** 本次七章通过门禁的同时，摘要偏短、相关工作过短、材料缺口仍然存在。终稿应连同待补清单一起审阅。
