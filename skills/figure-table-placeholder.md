# Figure & Table Placeholder — 图表占位符规范

> 起草论文正文时按需读取。**你(AI)不生成图**——只写占位符 + 完整说明,图由人工画。表可以用真实数字。

## 图:用占位符,不生成
正文中引用图的地方写占位符,格式:
```
[FIGURE N: <斜体标题>]
Note. <图注,自足——不看正文也能读懂:坐标轴含义+单位、图例、误差棒说明>
Data: <该图来自哪个结果字段,如 data/results/run_1_ours/final_info.json 的 top1_accuracy>
Supports: <支撑正文哪句论断>
```
- **每张图必须被正文引用**,按首次出现编号 Figure 1, 2, 3...
- **图注必须自足**(caption 独立成文,含坐标轴、单位、误差棒/CI 说明)
- 图内不放标题;色盲安全配色要求写在图注里

**方法章的架构示意图**没有结果数据来源,`Data:` 换成 `Source:`,指向 `idea.md` 里
对应的设计描述,并在 Note 里写清模块、数据流方向、以及哪些部分是本文新增的:
```
[FIGURE 1: <架构总览>]
Note. <各模块含义 + 数据流方向 + 哪块是本文贡献(建议用不同底色区分)>
Source: idea.md 第 4.1 节总体结构
Supports: <支撑正文哪句论断>
```

## "何时不画图"决策树(避免无意义占位)
| 数据形态 | 处理 |
|---|---|
| 数据点 <3 | 用文字或表格,不占位 |
| 单一均值/百分比 | 直接写数字,不占位 |
| 时间序列 | 折线图占位 |
| 多方法×多基准 | 分组柱状图占位 |
| 相关性 | 散点图占位 |
| 矩阵 | 热图占位 |

## 表:可以用真实数字
- 表格可以用结果库的真实数字(这些是**可引用**的)
- 用 booktabs 风格,右对齐数值,小数位一致
- 每列用箭头标方向(↑/↓),加粗最优值
- 3+ 方法对比时优先用表
- 复杂表也可用占位符 `[TABLE N: <说明>]`

## 通用
- 每个图/表必须**回链到源数据**(哪个 CSV/JSON 字段)+ 它支撑的正文论断
- 不用:饼图、3D、双 y 轴、截断 y 轴
- 最终图表由人工替换占位符,你的职责是写清"画什么、数据从哪来、支撑什么论断"
