# Figure & Table Placeholder — 图表占位符规范

> 起草论文正文时按需读取。**你(AI)不生成图,也不手写结果表**——图写占位符 + 完整说明,
> 结果表写表格占位符;程序负责编号、渲染和交叉引用。

## 结果表:一行占位符,程序按 CSV 渲染
结果目录里每个 CSV 是一张表(数据索引里列出了表名)。要在正文放这张表,单独一行写:
```
[TABLE: <表名> | caption: <表题> | note: <可选表注>]
```
- `<表名>` 必须是数据索引里的表名,原样复制;程序按 CSV 渲染整张表(含 `均值 ± 标准差`、
  按 ↑/↓ 加粗最优值),**你不要自己写表格单元格里的任何数字**。
- 表题用一句话说清“这张表比较了什么、在什么设置下”;表注写符号约定(如 † 表示数字取自原论文)。
- 正文里提到这张表,写 `[[TAB:<表名>]]`,程序替换成 `Table N`。**不要自己写表号。**
- 一张表在全文里只放一次。结果表之外的小表(如模块对照)仍可用 Markdown 表格,但不含结果库数字。

## 图:占位符 + 完整说明,图由作者按提示词补
正文里要放图的地方写占位块(紧跟一行以上的说明,到空行结束):
```
[FIGURE <id>: <图题>]
Type: <bar | line | scatter | heatmap | diagram>
Note. <图注,自足:坐标轴含义+单位、图例、误差棒说明;示意图写各模块含义与数据流方向>
Data: <数据来自哪张结果表的哪几列,如 主结果 表的 Top-1↑ 与 Params 列;示意图写 Source: idea.md 的第几节>
Supports: <支撑正文哪句论断>
```
- `<id>` 是短英文标识(如 `overview`、`ablation-bar`),全文唯一;**不要写图号**。
- 正文里提到这张图,写 `[[FIG:<id>]]`,程序替换成 `Figure N`(按占位块出现的先后编号)。
- 每张图必须被正文引用至少一次;图注必须自足(不看正文也能读懂);色盲安全配色写进图注。
- `Data:` 只能指向结果库里真实存在的表和列;示意图用 `Source:` 指向 idea.md 的设计描述。
  没有依据就不要放这张图。

## “何时不画图”决策树(避免无意义占位)
| 数据形态 | 处理 |
|---|---|
| 数据点 <3 | 用文字或表格,不占位 |
| 单一均值/百分比 | 直接写 `{{RES-xxx}}`,不占位 |
| 多方法×多指标 | 结果表(`[TABLE: ...]`)优先;需要可视化时用分组柱状图占位 |
| 趋势/曲线 | 折线图占位(数据须在结果表里) |
| 矩阵 | 热图占位 |

## 通用
- 不用:饼图、3D、双 y 轴、截断 y 轴
- 你的职责是写清“画什么、数据从哪来、支撑什么论断”;作者会拿着自动汇总的绘图提示词去补图
