# Math Formula — 数学公式规范

> 起草含公式的章节时按需读取。公式用 LaTeX 语法,符号必须与 Notation Table 一致。

## 语法形式
- **行内**:`$...$`,如 `$L_{\text{cls}}$`、`$\alpha$`
- **独立**:`$$...$$`,如 `$$\mathcal{L} = \frac{1}{N}\sum_{i=1}^{N} \ell_i$$`
- 公式引用:编号且正文必须引用,如 `$\mathcal{L}$ (Eq. 3)`

## 符号字体约定(LaTeX)
| 类型 | 形式 | 示例 |
|---|---|---|
| 标量 | 斜体 | `$x$`, `$L$` |
| 向量 | 粗体 | `$\mathbf{w}$`, `$\mathbf{x}$` |
| 矩阵 | 大写粗体 | `$\mathbf{W}$`, `$\mathbf{X}$` |
| 集合 | `\mathcal` | `$\mathcal{D}$`, `$\mathcal{S}$` |
| 期望/概率 | `\mathbb` | `$\mathbb{E}$`, `$\mathbb{P}$` |

## 符号规则
- **首次使用即定义**:出现新符号必须紧跟着定义,如 "$L_{\text{cls}}$ 为分类损失"
- **全文唯一**:同一符号全文只代表一个含义,不重载
- **遵守 Notation Table**:draft-v1.plan.md 冻结的符号表,正文不得改定义
- **沿用作者的记号**:`idea.md` 里作者已经定义过的符号和公式,直接用,不另起一套。
  作者写了 $g(\cdot)$ 就别改成 $f(\cdot)$——Notation Table 也应该是从那里抄来的
- 作者没定义但公式需要的符号,自己补定义时标一句来源,便于作者复核
- 缩写首次展开:如 "Cross-Entropy (CE) loss"

## 假设与定理
- 定理/假设前**正式列出全部前提假设**,给编号可引用(Assumption 1, Lemma 2...)
- 每个编号对象必须在正文被引用,不被引用的删除

## 与正文衔接
- 公式不是孤立存在:每个公式出现前要有引导句("我们定义损失为:"),出现后要有解释("其中 N 为样本数")
- 公式里的符号含义,即使直观也要在首次出现时说明
